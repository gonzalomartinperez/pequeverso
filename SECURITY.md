# Security policy

This is a static marketing site with no backend, accounts or payment processing (payments run on
Hotmart). If you find a vulnerability in this repository or the deployed site (for example a
content-security issue, a redirect open to abuse, or leaked data), please email
somospequeverso@gmail.com (the support mailbox in `config/site.ts`) with "security" in the
subject. We aim to acknowledge within 5 working days. Please do not open a public issue for security reports.
