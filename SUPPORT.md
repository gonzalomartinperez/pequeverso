# Support

| You need | Go to |
|---|---|
| Help with an order, access to a product or a refund | [pequeverso.com/soporte](https://pequeverso.com/soporte/) or the support mailbox, somospequeverso@gmail.com. Hotmart handles payment, delivery and refunds. |
| A question or bug about this repository | [Open an issue](https://github.com/gonzalomartinperez/pequeverso/issues/new/choose) using the matching form |
| A security vulnerability | Follow [SECURITY.md](SECURITY.md); do not open a public issue |
| Conduct concerns | See [CODE_OF_CONDUCT.md](CODE_OF_CONDUCT.md) |

Please never post payment details, purchase receipts or personal data in issues.
